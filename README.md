# PACMAN

A simple Pac-Man game developed in Java as a practice project.

## 🎮 Game Preview

![Pac-Man Game](images/game.png)

## Technologies

- Java
- Java Swing
- JFrame
- JPanel

## Features

- Pac-Man movement
- Ghost movement
- Collision detection
- Score tracking
- Game over functionality
